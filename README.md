# Jirapon — Portfolio

Live website: https://jorrorjira.github.io/

Graphic design, video editing and art direction, presented as an interactive space portfolio.

This repository contains the production static build. GitHub Pages serves `main` from the repository root. Development source is maintained separately; backups, development logs and source archives are not published here.

Built with Three.js, GSAP and Vite, based on the user-supplied Opus galaxy portfolio. Fonts: Inter Tight, Instrument Serif and IBM Plex Mono.

Portfolio content and decorative assets are not offered under an open-source or redistribution license. See [asset notes](models/CREDITS.txt).
